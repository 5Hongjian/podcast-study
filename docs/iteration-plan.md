# 后续迭代任务

这里是通用维护待办，不是任何用户的单期执行记录。未勾选项目尚未实现；按真实使用反馈决定优先级。

| 优先级 | 任务 | 验收条件 |
| --- | --- | --- |
| P1 | 字幕可用性判断评估 | 完整字幕、无时间字幕、部分字幕、摘要冒充全文和暂时访问失败都走正确分支 |
| P1 | 用户配置升级评估 | 至少两个版本间更新后，用户覆盖与已有运行记录逐字保留，未覆盖项目采用新默认 |
| P1 | Google Docs 导图和跳转验收 | 导图可读，主题与正文对应，重点片段连接到经验证的播放时间；不支持的能力有明确替代 |
| P2 | 长节目分段理解改进 | 多段底稿合并后仍有统一主线、因果解释和反例，无重复堆叠摘要 |
| P2 | 转录中断恢复适配 | 使用实际可用的 Buzz 任务或进程状态恢复，不重复下载、转录；按目标系统验收 |
| P2 | 新用户首次安装体验 | 无 Buzz/无模型设备只在必要时安装，型号选择与设备匹配，完成最小转录验证 |

每次选定任务后新建分支，记录具体变更及验证结果。若未来需要常驻后台、自动唤醒或批量队列，应作为明确的新能力设计，不能把技能文字描述当作已部署实现。
