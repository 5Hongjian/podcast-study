# Podcast Study · 播客精读

Podcast Study 将播客精读工作流封装为可调用技能，串联字幕获取、文字稿检查、内容分析与网站精读内容生成。输入节目标题或链接，可获得全文总结、思维导图、相关问答与原文导航，并留下自己的思考，重点解决三类问题：

- **缺少原生字幕，总结依据不完整**：优先获取完整原生字幕；无法获取时，通过 Buzz 与本地模型转录，以完整节目为分析依据，减少仅依赖零散片段或第三方评论造成的遗漏与偏差。
- **提高收听与理解效率**：面对一到两小时的长节目，先通过笔记与思维导图掌握全貌、理解观点、论证及适用条件，再通过时间导航按需回听感兴趣的片段，减少全程收听和反复查找的时间成本。
- **记录费时、听后难留存**：整理关键内容并保留可标注的原文，用户随手记录感想、选择 takeaway；区分节目观点、AI 启发和用户自己的表达，方便未来检索与更新。

## 工作流程

提供标题或链接 → 原生字幕优先，必要时 Buzz 本地转录 → 输入检查与评估 → 统一底稿检查 → 问答与总结生成、最终评估 → 发布核验并交付网站 → 按版本归档、清理可替代的本地导出稿与临时文件。清理失败只恢复清理，不拖住已核验的网站交付。

[查看完整工作流图与异常处理说明](docs/workflow.md)

本仓库分发可安装的 Skill、文字稿与内容检查脚本、空白任务模板，以及安装和回归测试。执行 Agent 负责调用工具与推进流程，目标网站负责页面渲染和个人笔记存储；安装此 Skill 后仍需可用的网站交付能力。

## 固定网站结构

1. **AI 全文总结**：覆盖主要议题、观点与分歧，帮助判断是否值得收听。
2. **思维导图**：图状/文字模式呈现同一份已验收的主题、主要论点、论据或条件，连接原文与可验证的回听位置。
3. **相关问答**：选择值得深入解释的问题，讲清推理、案例及适用条件，不逐主题重复概览；用简洁数字引用定位原文。
4. **我的思考**：收纳用户对原文的标注与感想；takeaway 由用户选择，AI 提炼先作为候选。

开头不放发布日期、整理日期和处理工具等元数据；来源与限制简洁收尾。网页呈现约定包含图状/文字切换、累计层级、缩放及可隐藏原文栏。播放器不支持精确跳转时明确提供节目链接与已知时间，无时间依据则只定位原文。

内容与页面结构统一，不读取个人内容偏好或本地格式覆盖文件。完整规则在 [固定网站内容规范](skills/podcast-study/references/document-format.md)。

文字稿检查使用随技能提供的 Python 标准库脚本；用法和评估边界见 [文字稿检查规则](skills/podcast-study/references/input-quality.md)。程序检查不能替代音频核对，也不将缺失证据判为通过。

通过输入检查后的内容使用统一结构与版本。运行 `check_content.py` 检查底稿和最终阅读包，依据 [内容契约与评价标准](skills/podcast-study/references/content-quality.md) 记录语义评估；缺少依据或重要问题未解决时保留草稿。直接输出到目标网站；用户笔记独立于生成内容。

## 安装与调用

可以直接把下面的话发给 Codex：

> 请从 https://github.com/5Hongjian/podcast-study 安装 skills/podcast-study。保留我已有的单期任务记录、来源资料和个人笔记。

也可以在本机使用 Python 3.10+ 和 Git：

```sh
git clone https://github.com/5Hongjian/podcast-study.git
cd podcast-study
python3 scripts/install.py
```

安装器默认使用 `~/.agents/skills/podcast-study`。如果这里已有指向旧安装的符号链接，会保留链接并更新其目标；也可用 `--skills-dir` 指定位置。Codex 的用户级技能目录见 [官方技能文档](https://learn.chatgpt.com/docs/build-skills)。如果技能未出现，重启 Codex。

调用示例：

> 使用 $podcast-study 整理这个播客：〈标题或链接〉。按固定结构发布网站，核验原文与标注并保留可恢复的该期内容后，清理本地导出稿及临时素材。

新用户只有在确实需要本地转录时，才按 [Buzz 安装指引](skills/podcast-study/references/buzz-setup.md) 检查设备、安装缺少的 Buzz 与合适模型。已有完整字幕时不下载这些组件。
