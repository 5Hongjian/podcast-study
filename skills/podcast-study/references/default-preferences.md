# 默认偏好

本文件只有通用默认值，不含作者的个人资料、历史任务或授权。先读取这些默认值，再用用户本地设置和本次指示覆盖。

- 输出语言：简体中文；专名必要时保留原文，用户指定其他语言时采用指定语言。
- 目标：读懂全期核心问题、推理及适用条件，并能回听关键片段。
- 详略：优先把关键问题解释清楚，条数和长度随节目内容调整，不凑固定数量。
- 文档：Google Docs；顺序为个人 takeaway → 一句话主线与带时间导航的思维导图 → 关键问题解释 → 来源与必要说明。细节见 [默认文档结构](document-format.md)。
- 个性化：没有背景资料时，写面向一般听众的应用启示；不推测用户职业、资产、经历或立场。
- 输入：完整原生字幕优先；实际缺失时才考虑 Buzz 与本地多语言模型。
- 模型：按当前机器能力选择；不固定模型大小、版本或本地路径。
- 临时文件：默认流程在 Docs 写完并核验后，最后把本次生成的音频和转录副本移入系统废纸篓；遵循当前用户已有授权和工具权限。保留可复用的 Buzz 与模型，不永久删除或清空废纸篓。
- 安装权限、云服务费用和账号连接：本文件不预先代用户授权；按当次请求与实际权限处理。
- 个人身份、默认账号、Docs 文件夹、固定输出文档、时区：未设置，需要时使用当前环境或询问真正缺失的信息。

用户只改一篇时不保存为全局偏好；明确长期修改才写入用户自己的 `preferences.md` 或 `document-format.md`。
