# 网站内容结构与写作标准

这是固定的网站内容与写作规范，生成或修改节目内容时读取。输出简体中文，专名必要时保留原文；目标是帮助用户掌握全期、选择精听位置并保留可追溯的个人记录。内容和页面结构统一，不应用个人偏好或本地格式覆盖；条数和篇幅仍随节目内容调整，不凑数。

## 阅读顺序

### 1. AI 全文总结

先交代全期讨论的核心问题，再精炼覆盖主要主题、观点和必要分歧，帮助用户判断是否值得听、重点听哪里。篇幅随内容复杂度调整；不以少数金句代替全貌，也不把尚未建立背景的个人建议放在开头。保留影响结论的条件和不确定性，避免在总结、导图和问答中重复整套摘要。

不要在开头放发布日期、整理日期、处理工具、冗长元数据或版本记录。必要的节目名、集数、嘉宾可作为简短副标题。

### 2. 思维导图与回听导航

先通读完整文字稿，识别议题与论点转折，再组织层级：一级为主要主题，二级为该主题下的主要论点，三级为支撑论据、案例或适用条件。节点用短句表达实质内容，不把案例升级为主要论点，不按固定时长机械分段，不强行补齐三级。每次主题切换以原文位置为依据；同一主题再次出现时保留各段位置，不虚构一个连续时间范围。

图状与文字大纲直接呈现通过底稿验收的同一份 nodes，不再次抽取或编写层级；一级只展示主题，二级在一级基础上增加论点，三级再增加依据。主题节点可汇总多个出处，但每个论点须有直接支持它的原文。重点节点关联对应问答与原文，为论证保留上下文，不只定位一句金句。节点 ID 与引用编号分别管理，不假定一个主题只有一条出处。

网站呈现时支持图状／文字切换、累计层级、缩放、拖动和适配视图；切换呈现保留选择和定位。页面内部链接只使用实际存在且验证过的节点或原文范围。渲染后检查中文、字号、层级和实际跳转目标。

### 3. 相关问题与回答

每节先直接回答，再按内容需要展开推理、案例／白话解释和适用条件。问题数量随节目变化，不凑固定数量；优先选择需要解释原因、分歧或边界的问题。全貌由总结与导图覆盖，不要求每个主题另写一组问答；简单背景或事实可在概览中讲清。重要推理、反例和后置条件仍须有充分说明，不能只留短标题。

至少解释观点之间的因果、前提或区别。若一段只把原结论换个措辞，需回到来源补足“为什么”。优先使用节目原有案例；新增理解示例明确标注“整理者示例”，不能归给嘉宾。预测保持预测语气，不从类比推出确定赢家或时间表。

在需要依据的具体句段末尾放低干扰的数字引用，采用浅灰小圆形数字。引用紧邻所支持的观点；一个回答依赖多处原文时分别标记，不用末尾一个数字笼统覆盖整段。

同一期阅读页面中，相同证据位置复用同一编号；编号与持久引用记录关联，局部修改不重新编号既有引用。引用须能解析到 `source_version_id`、稳定 `segment_id`、原文摘录及片段内起止字符位置；字符位置统一以 Unicode 码点计数、从 0 开始、左闭右开，并核对摘录与源文本一致。正文引用、导图与笔记共用原文定位，不把显示编号当作原文 ID。修改正式文字稿时保留旧版本及映射，核验后再迁移引用，不能静默指向另一句话。

网站点击引用时展开原文栏，定位并高亮原句；原文栏可隐藏、调宽、独立滚动，隐藏时保留阅读位置和未完成笔记。只有明确定位操作才改变原文阅读位置。定位范围与摘录必须一致，不伪装成精确的音频跳转。

原文定位与音频定位分别记录。回听链接只用播放器实际支持且已验证的格式；不支持时显示节目链接与已知时间。只有段落起点时标“段落起点”，不能显示成精确论点切换；没有可靠时间时标“时间未核验”，仍可定位原文。不同媒体版本分别核验时间轴，不猜测参数或生成无效链接。出处缺失或不支持论点时先修复／删除该论点；无法提供定位时明确标记，不放可点击的假引用。

### 4. 我的思考

阅读中允许在正式文字稿上选中原句，只高亮或附加想法；另提供整期感想入口。笔记保留原文摘录、版本和定位、用户实际表达的内容、作者及记录时间；高亮只代表关注，不等于赞同。原位笔记与文末汇总指向同一条记录，修改同步，不维护两份独立文本。保存失败保留输入并明确提示，不显示已保存；刷新与重新生成内容后仍可读取已保存记录。

Takeaway 是笔记的重要性标记，可由用户直接选择或编辑后保留，也可以是一条疑问；不要求固定条数或行动计划。用户触发 AI 整理时先给草稿，保留原笔记，用户采纳后再记录为其确认的内容，并保留 AI 辅助标记。没有笔记时仅提供可选的“AI 启发候选”，不编造用户感想，不自动写成用户立场。尚无个人记录时保留简短入口，不填充虚构心得。

来源与必要说明放在文末或相应引用处，保留节目链接、必要外部核验和影响理解的输入疑点，避免占据主阅读区。外部核验只针对必要事实，不将每期自动扩成研究报告。

## 内部底稿

内容数据只按 [统一底稿与评价契约](content-quality.md) 保存一套层级、论点、引用及覆盖映射；总结和问答使用这套依据。缺失的时间保持未知，嘉宾观点、整理者示例、AI 推导与用户笔记分别标识。

完整原文、引用与用户记录须能跨次读取；网站从发布包中的全文显示原文，不依赖本地导出稿。归档、恢复与清理统一遵循 [任务记录规则](task-state.md)，不额外生成用户未要求的章节。

## 验收与修订

正式通过条件只在 [内容契约与评价标准](content-quality.md) 定义，页面按其中的核验范围检查。先修内容再修局部排版；输入缺段回输入阶段，错链只修导航，不因小修补重写全篇。
